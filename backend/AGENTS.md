# راهنمای ساختار و مسئولیت‌های بک‌اند (Backend Architecture Guide)

این پوشه شامل کدهای سرور بک‌اند اپلیکیشن مدیریت پروژه کانبان است که با استفاده از Python و فریم‌ورک FastAPI توسعه داده شده است.

## ۱. اهداف و مسئولیت‌های اصلی

- ارائه فایل‌های استاتیک فرانت‌اند Next.js از مسیر ریشه (`/`).
- ارائه APIهای احراز هویت با نام کاربری و رمز عبور ثابت (`user` / `password`).
- مدیریت پایگاه داده محلی SQLite (`kanban.db`) به‌صورت خودکار در صورت عدم وجود.
- مدیریت عملیات CRUD ستون‌ها و کارت‌های برد کانبان برای هر کاربر.
- برقراری ارتباط با مدل هوش مصنوعی OpenRouter (`openai/gpt-oss-120b`) و اعمال تغییرات ساختاریافته روی برد.

## ۲. ساختار پوشه‌ها و فایل‌ها

```
backend/
├── app/
│   ├── __init__.py        # پکیج اصلی برنامه
│   └── main.py            # نقطه ورود اصلی FastAPI، پیکربندی CORS، مسیرهای پایه و ارائه فایل‌های ایستا
├── static/
│   └── index.html         # فایل استاتیک آزمایشی مرحله ۲ (در مرحله ۳ با خروجی Next.js جایگزین می‌شود)
├── tests/
│   ├── __init__.py        # پکیج تست‌ها
│   └── test_api.py        # آزمون‌های واحد مسیرهای API و ارائه فایل‌های ایستا
├── pyproject.toml         # تعریف وابستگی‌ها و پیکربندی پکیج با ابزار uv
└── README.md              # معرفی مختصر بک‌اند
```

## ۳. نحوه اجرای محلی

برای اجرای مستقل سرور بک‌اند با استفاده از پایتون محلی:

```bash
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

پس از اجرا:
- صفحه اصلی در آدرس `http://localhost:8000/` در دسترس خواهد بود.
- مستندات خودکار API در آدرس `http://localhost:8000/docs` در دسترس است.
- مسیر بررسی سلامت در آدرس `http://localhost:8000/api/health` پاسخ می‌دهد.
