# Cyberpunk Kanban Board MVP

A minimal, high-contrast Dark Mode Cyberpunk Kanban web application built with Next.js and Tailwind CSS.

## Features

- Single board with 5 default customizable columns.
- Column management: Add new columns, delete columns, rename columns, and reorder columns via drag and drop.
- Customizable columns per row: Toggle between horizontal scroll and 2, 3, 4, 5, or fit-to-screen multi-row grid to eliminate horizontal scrolling.
- Visual Matrix Grid HUD: Customize background grid visibility, density (24px, 48px, 72px), neon emission color (cyan, magenta, yellow), and glow intensity.
- Card operations: Drag and drop cards across and within columns, add new cards (title and details), and delete cards.
- Pre-populated futuristic dummy data on initial load.
- High-contrast Dark Mode Cyberpunk aesthetic with neon accents.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

The application will be available at http://localhost:3000.

## Running Tests

```bash
cd frontend
npm run test
npm run test:e2e
```
