# Frontend - Cyberpunk Kanban Board MVP

Next.js Client-Side Rendered (CSR) web application for the Cyberpunk Kanban Board.

## Scripts

- `npm run dev`: Starts the Next.js development server.
- `npm run build`: Compiles production bundle with Webpack and Tailwind CSS.
- `npm run start`: Runs production server on http://localhost:3000.
- `npm run test`: Executes unit tests with Vitest.
- `npm run test:e2e`: Runs end-to-end integration tests with Playwright.
